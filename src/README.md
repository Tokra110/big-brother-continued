# Big Brother Continued

Big Brother Continued brings the classic Big Brother radar and surveillance mod to Factorio 2.1.

## Features

- Nine levels of radar amplification increase nearby reveal range and distant scan range.
- Nine levels of radar efficiency accelerate distant-sector scanning.
- Surveillance centers keep vehicles and trains visible on the map.
- Advanced surveillance equips big electric poles with automatic map coverage.

## Continuing an existing factory

Factories using the Factorio 2.0 WIP mod can continue with this release:

1. Disable `big-brother`.
2. Enable `big-brother-continued`.
3. Load the factory and save it under a new name the first time.

Entity, recipe, and technology prototype names are retained. On first load, the continuation rebuilds its runtime tracking from the entities already present in the factory.

Do not enable both mods together. They define the same prototypes.
